# Портфолио — Евсеенкова Александра

Статический сайт: чистый HTML/CSS/JS, без сборки и зависимостей.

## Структура

```
index.html              главная
about.html               обо мне
cases/
  bspb.html               кейс «Банк Санкт-Петербург»
  yandex360.html           кейс «Яндекс 360»
  vkusvill.html            кейс «ВкусВилл»
assets/
  css/                    tokens → base → layout → components (+ case.css на кейсах)
  js/                     i18n, cursor, scroll, reveal, main
  fonts/                  Onest + Inter, self-hosted woff2
  img/, video/            все изображения и видео кейсов, портреты, путешествия
  cv-evseenkova-aleksandra.pdf
```

## Как запустить локально

Любой статический сервер подойдёт. Проще всего:

```bash
cd Portfolio
python3 -m http.server 4173
```

Открыть `http://localhost:4173`. **Открывать через двойной клик по `index.html` (file://) не стоит** — часть эффектов (инерционный скролл, курсор) в некоторых браузерах работает нестабильно без реального сервера из-за политики безопасности для `file://`.

## Как редактировать текст

Каждый переводимый кусок текста продублирован прямо в HTML:

```html
<span data-lang="ru">Русский текст</span>
<span data-lang="en">English text</span>
```

Правьте нужный `<span>` — переключатель RU/EN в шапке сам покажет то, что нужно. Если меняете факт (не перевод), меняйте оба span одинаково.

## Как заменить фото/видео кейсов

Файлы лежат в `assets/img/cases/{bspb,y360,vkusvill}/` и `assets/video/`. Заменяйте файл с тем же именем — путь в HTML менять не нужно. Рекомендуемый формат: JPEG, ширина до 1600px, качество ~80 (держит вес в разумных пределах для веба).

## Деплой

Папку `Portfolio` можно целиком перетащить в [Netlify Drop](https://app.netlify.com/drop) или залить на Vercel/GitHub Pages — никакой сборки не требуется. Важно сохранить относительную структуру папок как есть.

## Что стоит донастроить

- **CV** (`assets/cv-evseenkova-aleksandra.pdf`) — сейчас на русском языке независимо от переключателя RU/EN. При желании можно добавить английскую версию и подставлять её на EN.
- **Домен и favicon** — фавикон сейчас простая монограмма (`assets/favicon.svg`), можно заменить на что-то более персональное.
