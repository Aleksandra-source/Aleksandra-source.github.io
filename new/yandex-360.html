Яндекс 360

Сократила переходы между админками и упростила поддержке работу с большим объёмом информации

Контекст

У продукта есть собственная служба поддержки, которая помогает пользователям решать вопросы, связанные с телемостом, почтой, мессенджером и другими сервисами Яндекс 360

Проблема

Чтобы обработать одно обращение, сотруднику поддержки приходится переключаться сразу между несколькими административными панелями. Это замедляет работу и увеличивает время ответа пользователю

Задача

Спроектировать единую административную панель по пользователю, которая поможет сотруднику быстро получить общую информацию о пользователе по сервисам Яндекс 360

UX-аудит

Провела анализ текущей административной панели, чтобы понять где саппорт теряет время

Выводы

  • сейчас для поиска информации, необходимой для решения проблемы саппорту приходится сделать минимум 5 шагов (если он знает где ее искать);
  • информация по сервисам пользователя находится в разных местах;
  • не сразу видно полезную информацию о статусе и тарифе пользователя

User flow

Предположила, из каких шагов состоит работа с запросом и что важно для быстрого решения, что позволило сформулировать несколько гипотез

  1. H1Если сократить переходы между админками, это позволит ускорить обработку обращений
  2. H2Если собрать данные из разных сервисов в одной панели, сотруднику не придётся переключаться между ними — работа саппорта упростится
  3. H3Если показывать информацию о тарифе и сервисах, это позволит сотруднику быстрее выявлять проблему пользователя

Бенчмаркинг

Проанализировала, как CRM-системы структурируют большие объёмы данных, и на этой основе сформулировала новые гипотезы

  1. H4Размещение ключевой информации о пользователе рядом с чатом позволит быстрее идентифицировать пользователя
  2. H5Группировка информации по сервисам в отдельных вкладках поможет быстрее находить нужные данные по пользователю
  3. H6Добавление истории обращений поможет быстрее понять контекст проблемы и избежать повторной проверки фактов

Юзабилити-тест

Я провела юзабилити-тест с 8 участниками: каждый искал заданную информацию в старой и новой версиях админ-панели

Результат

  • в новом интерфейсе количество шагов сократилось в 2 раза
  • вся информация о пользователе теперь находится в одном окне
  • 7 из 8 участников справились быстрее, чем в старой версии
